\# Campus Smart Parking System – Java Assignment 1



\## Project Overview

This repository contains the implementation of a Campus Smart Parking System using Java. It demonstrates object-oriented programming concepts, parking-slot management, vehicle handling, fee calculation, validation, and system design.



\## Technologies Used

\- Java 21

\- Object-Oriented Programming

\- Arrays and Jagged Arrays

\- Inheritance and Polymorphism

\- Encapsulation and Abstraction

\- Exception and input validation concepts

\## How to Compile and Run

1\. Install Java Development Kit (JDK 21).

2\. Open PowerShell or a terminal.

3\. Navigate to the required task folder.

4\. Compile the Java source file:

&#x20;  ```powershell

&#x20;  javac FileName.java

&#x20;  ```

5\. Run the program:

&#x20;  ```powershell

&#x20;  java ClassName

&#x20;  ```



Replace `FileName.java` and `ClassName` with the actual source filename and public class name for that task.



\## Assignment Contents

\- Tasks 1–12: Java implementation and design exercises.

\- UML: Class diagram showing the system structure and relationships.

\- Test evidence: Screenshots and test results for program execution.

\- Final report: Design decisions, pseudocode, test tables, and complexity analysis.



\## Final Design Challenge

The final design extends the parking system to support:

\- E-bikes with a flat parking fee.

\- Delivery vans with time-dependent parking fees.

\- One-day visitor passes.

\- A five-floor parking facility with different floor capacities.
